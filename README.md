## Встановлення Python 3.11+

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
```

Linux/macOS: `source .venv/bin/activate`. Усі команди виконуються з кореня
репозиторію або з Lab_02. Залежностей часу виконання поза стандартною бібліотекою немає.

## Запуск і перевірка

```text
python -m book_manager
python -m book_manager.main
book-manager --interactive
python -m book_manager --export summary.json
python -m book_manager --benchmark --benchmark-output benchmark.json
python -m unittest discover -s tests -v
```

`--interactive` відкриває меню першої роботи з порожнім каталогом.
`--export` експортує підсумок демонстраційного каталогу з п’яти книг;
дані інтерактивного сеансу не зберігаються. Результати запуску й benchmark
знаходяться в `docs/results`, звіт — `Lab_02/report/report.docx`.

## Операції варіанта 2

Унікальні автори (set), групування (defaultdict), індекс назв (dict із tuple
усіх однойменних книг), точний пошук назви без урахування регістру,
фільтр точного року, найбільша книга, середня кількість сторінок,
стабільне сортування за роком і Counter книг кожного автора.

Приклад: 5 книг; 4 автори; Іван Франко — 2 книги; 1911 рік — 2 книги;
найбільша — «Кобзар», 240 сторінок; середнє — 160.00.
Обсяги умовних видань є демонстраційними значеннями.
Порожній каталог повертає середнє 0.0, найбільшу книгу None та порожні колекції.

## Складність та benchmark

| Операція | Час | Додаткова пам’ять |
| --- | --- | --- |
| Лінійний пошук | O(n) | O(1) |
| Побудова індексу | O(n) у середньому | O(n) |
| Пошук у dict | O(1) у середньому, O(n) у гіршому | O(1) |
| Групування, Counter | O(n) у середньому | O(n) / O(a) |
| Фільтрація | O(n) | O(n) |
| Сортування | O(n log n) у гіршому | O(n) |

Довжину текстових ключів вважаємо обмеженою; хешування рядка залежить від
його довжини. n — кількість книг, a — кількість авторів.
Benchmark: 1 000, 10 000, 100 000 записів `(ID, назва)`, 200 пошуків у серії,
5 повторів, медіана часу на один пошук. Окремо виміряно побудову індексу.
Перевіряються останній ID та відсутній ID; перший ID не був би показовим
для лінійного проходу. В обох контейнерах використовуються ті самі об’єкти.
Точні числа залежать від комп’ютера й навантаження; тести не вимагають
фіксованого співвідношення швидкостей.

## Додаткові можливості

Універсальна фільтрація, універсальне сортування, closure фільтра сторінок,
параметризований decorator з functools.wraps, Counter, benchmark та JSON export.
Decorator передає *args/**kwargs, повертає результат і не приховує винятки;
час передається через logging, а не домішується до обчислюваних значень.
